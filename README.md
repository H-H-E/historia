# HISTORIA

HISTORIA is a proposed historical social network that presents events through the perspectives and information available to people at the time. This repository currently contains the project outline only; research, architectural decisions, datasets, and application implementation remain future work.

## Project brief

The complete [project brief](docs/project-brief.md) describes the goals, requirements, and proposed deliverables. Its requirements are aspirations, not claims of completed work.

## Planned work

1. Research the reference technology and historical data sources, including their licenses and limitations.
2. Define the historical simulation model, including provenance, uncertainty, and what actors could know at a given time.
3. Compare data formats and architectures; specify a versioned canonical model and validation rules.
4. Design source ingestion, simulation modes, and a reproducible content pipeline with human review.
5. Design the social feed, time controls, discovery, accessibility, and learning interactions.
6. Evaluate deployment, storage, performance, and operating costs.
7. Build and evaluate a source-grounded vertical slice with automated and human review.

## Intended deliverables

- Product specification and architecture decisions
- Canonical data and source integration specifications
- AI prompt library and content pipeline design
- UX, visual design, and implementation specifications
- Working application, evaluation report, and development roadmap

See the [full brief](docs/project-brief.md) for details. No technology stack, historical sources, or license has been selected yet.
